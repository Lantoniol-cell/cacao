Dictionnaire des variables

Les 328 colonnes du jeu de données, une par ligne. Cherchez par nom ou par description, filtrez, triez en cliquant sur un en-tête, et cliquez sur une ligne pour ouvrir sa fiche complète.

Chaque fiche est construite par scripts/45_dictionnaire_qualite.py à partir du code de collecte. Périodes, complétude et contrôles sont calculés sur les données réelles. Ce qui n’est pas documenté dans le code est marqué « Non documenté ».

NoteComment lire « intérêt pour la prévision »

Aucun horizon n’est attribué à la main. La fiche rapporte trois mesures différentes, qui ne prouvent aucune causalité :

  1. Rang SHAP : le meilleur rang des variables dérivées de cette colonne dans le modèle, par cible et horizon (par exemple « sens 20 : 12/142 »). Il dit sur quoi le modèle s’appuie, pas si cela améliore la prévision.
  2. Association : les corrélations de rang retenues avec la cible future, dans l’échantillon 2010-2026, après correction des tests multiples.
  3. Perte au retrait de la famille, hors échantillon. Une valeur positive avec astérisque signifie que la famille aide le modèle de façon nette.

Dans tous les cas, aucun modèle à facteurs ne bat le benchmark sans facteurs : l’intérêt prédictif reste une hypothèse à tester.
